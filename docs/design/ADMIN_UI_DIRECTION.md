# EasyTire Admin — визуальное направление

Статус: accepted  
Дата: 2026-07-31  
Владелец: Mister Red

## Характер

Админка должна ощущаться как спокойный рабочий инструмент: строгая, быстрая и очень понятная. Это не типовой шаблон dashboard и не витрина с декоративными эффектами. Основной образ — современная чёрно-белая редакционная система с хорошей типографикой и большим количеством воздуха.

## Базовые токены

| Роль | Значение |
|---|---|
| Основной фон | `#F5F5F2` |
| Поверхность | `#FFFFFF` |
| Основной текст | `#111111` |
| Вторичный текст | `#666660` |
| Граница | `#D8D8D2` |
| Hover | `#ECECE7` |
| Основная кнопка | фон `#111111`, текст `#FFFFFF` |
| Focus ring | `#111111`, 2 px с внешним отступом |

Цвет используется только семантически: успех, предупреждение, ошибка и информационное состояние. Он не становится декоративным акцентом интерфейса. Контраст текста и интерактивных элементов должен соответствовать WCAG AA.

## Каркас

- фиксированная боковая навигация на desktop и выезжающая панель на mobile;
- компактная верхняя строка: заголовок раздела, поиск, локаль `NO / RU`, пользователь;
- ширина контента ограничивается смыслом экрана, а не растягивается автоматически;
- таблицы имеют липкий заголовок, явные состояния пусто/загрузка/ошибка и не прячут основные действия в hover;
- формы строятся короткими секциями с постоянной нижней панелью сохранения только на длинных страницах;
- критические действия требуют подтверждения с точным названием объекта и описанием последствия.

## Компоненты первой очереди

`AppShell`, `Sidebar`, `Topbar`, `PageHeader`, `Button`, `IconButton`, `TextField`, `Select`, `Checkbox`, `Tabs`, `DataTable`, `Pagination`, `Badge`, `Alert`, `EmptyState`, `Dialog`, `Toast`, `Skeleton`.

Компоненты принадлежат проекту и документируются на отдельной закрытой странице `/admin/ui` только в local/staging. Для Playwright используются доступные роли/labels и редкие стабильные `data-testid`, а не селекторы по расположению.

## Локализация

Навигация, подписи, ошибки и системные сообщения поставляются на норвежском Bokmål и русском. Переключение языка не должно сбрасывать открытую страницу, фильтры или незавершённую форму.

## Запрещено

- Filament и любые готовые admin-panel frameworks;
- готовые dashboard templates;
- градиенты, glassmorphism, тяжёлые тени и декоративная анимация;
- иконки без текстовой подписи для неоднозначных действий;
- хранение бизнес-правил в Blade/Livewire-компонентах;
- отдельный SPA без доказанной необходимости.
