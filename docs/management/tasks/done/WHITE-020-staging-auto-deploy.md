# WHITE-020: staging и автоматический deploy

Исполнитель: Mister White  
Модель: Codex Terra  
Статус: done, принят Mister Red после двух циклов исправлений

## Цель

Поднять изолированный staging на `staging-easytire.bethub.fun`, куда ветка `main` разворачивается одним Git push.

## Границы

- не менять существующие сайты и vhost;
- не переносить локальные или NDI-секреты;
- не выполнять внешние заказы и уведомления;
- не выводить DB-пароль в логи/отчёт;
- переключать релиз атомарно только после сборки, миграций и тестов.

## Критерии приёмки

HTTPS валиден, Nginx-конфигурация проходит проверку, отдельные пользователь/БД/repository созданы, неуспешный deploy не меняет `current`, описан rollback и Git remote.
