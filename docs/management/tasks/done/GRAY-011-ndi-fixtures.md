# GRAY-011: синтетические XLSX-фикстуры NDI

Исполнитель: Mister Gray  
Модель: Codex Terra high  
Статус: done, принят Mister Red после исправления проверки ведущего нуля

## Цель

Создать малые XLSX-файлы с фактическими заголовками NDI и полностью синтетическими значениями для тестов импортера.

## Критерии приёмки

Есть валидные шины/диски/остатки и ошибки duplicate/decimal/negative; SKU хранится текстом и включает ведущий ноль; представлены семь складов и stock-only; production SKU, цены, credentials и PII отсутствуют; каждый workbook прошёл inspect и визуальный render.
