# WHITE-001: инвентаризация текущего сайта EasyTire

Исполнитель: Mister White  
Постановщик и ревьюер: Mister Red  
Статус: superseded by `BLUE-001`, закрыт без отдельной реализации

## Цель

Зафиксировать существующий контент и пользовательские сценарии сайта https://easytire.no, чтобы при редизайне не потерять услуги, формы, цены, контактные данные и SEO-сущности.

## Входные данные

- текущий публичный сайт;
- материалы из `docs/primary`;
- `docs/project/PROJECT_BRIEF.md`.

## Границы

- не проектировать архитектуру;
- не тестировать и не использовать NDI credentials;
- не менять исходные материалы;
- не писать production-код;
- не считать текущие цены окончательными требованиями;
- отметить противоречия, но не выбирать за заказчика правильный вариант.

## Ожидаемый результат

Создать `docs/research/CURRENT_SITE_INVENTORY.md` со следующими разделами:

1. Карта страниц и переходов.
2. Список услуг.
3. Все обнаруженные цены и сезонные скидки.
4. Список форм и полей каждой формы.
5. Сценарии записи.
6. Контактные данные и внешние ссылки.
7. Контент, который потребуется перенести.
8. SEO-заголовки/темы существующих страниц.
9. Ошибки, дубли и противоречия.
10. Список вопросов заказчику.

## Критерии приёмки

- каждая доступная страница учтена;
- формы описаны на уровне полей и ветвлений;
- факты отделены от предложений;
- присутствуют URL источников;
- документ не содержит секретов и персональных данных пользователей;
- результат можно использовать для оценки миграции.
