# Security note

Дата: 2026-07-31

В исходном скриншоте переписки внутри `docs/primary` видны тестовые учётные данные NDI.

До создания удалённого репозитория необходимо:

1. Не публиковать исходный скриншот в открытом или общем репозитории.
2. Сделать редактированную копию скриншота без логина, пароля и клиентского номера для обычной документации.
3. Хранить оригинал только в защищённом хранилище проекта с ограниченным доступом.
4. После завершения аудита запросить у NDI ротацию тестового пароля.
5. Передавать credentials приложению только через `.env`/secret storage.

Новые документы проекта не содержат значения выданных логина и пароля.
