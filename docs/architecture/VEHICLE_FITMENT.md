# Vehicle fitment boundary

The VehicleFitment client is disabled by default and never calls remotely without both explicit enablement and an API key. Registrations are normalized in memory, cache keys are SHA-256 hashes with a short TTL, and no raw registration, VIN, owner data or response body is persisted or logged.

The technical lookup endpoint is `https://akfell-datautlevering.atlas.vegvesen.no/enkeltoppslag/kjoretoydata`. The adapter follows the current official `Enkeltoppslag` OpenAPI contract: it reads `kjoretoydataListe`, then approved axle combinations under `godkjenning.tekniskGodkjenning.tekniskeData.dekkOgFelg`. `dekkdimensjon` is treated as a string and only conservative metric sizes such as `205/55 R16` are mapped into catalog filters. Unknown formats are ignored rather than inferred.

Statens vegvesen documents the `SVV-Authorization: Apikey …` header and a 50,000-calls-per-key daily limit. The endpoint and header remain configurable, but no key is stored in the repository. The UI must not assert automatic compatibility: the buyer explicitly confirms a returned size, and manual catalog selection remains available whenever the service is disabled, unavailable, or has no safely parsed size.
