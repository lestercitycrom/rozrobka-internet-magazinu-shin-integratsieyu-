## Собственные исправления и улучшения — отдельно от композиции по ТЗ

1. Удалены поздние CSS-правила, отменявшие правильный hero/finder, мобильные заголовки и планшетный стек.
2. Исправлено наследование типографических ролей, чтобы H2/H3 не получали размер H1; нормализован крупный заголовок товара.
3. Исправлен реальный DOM-порядок формы, а не только её визуальная перестановка.
4. Белая рамка focus на светлом finder заменена заметной тёмно-красной.
5. Вход в комплекты очищен от ошибочного дублирующего перехода на балансировку.
6. Пустой каталог без фильтров больше не советует «убрать фильтры»; предлагается осмысленная помощь с подбором.
7. Карусель из двух акций использует два desktop-места и доступна целиком на 390/320, без недостижимого предложения.
8. Ошибка фото акции показывает оформленный fallback, а не значок битой картинки/обломок alt.
9. Видео не декодируется заранее вне экрана, останавливается под модальным окном; reduced-motion запрещает autoplay, но не ручное воспроизведение.
10. Условия акций доступны в native-dialog даже при длинном тексте; десять циклов hover не сдвигают CTA.
11. Устранена узкая полоска фото в карточках услуг на 320 px; изображение и текст располагаются естественно друг под другом.
12. При сокращении заголовков «О нас»/контактов сохранены назначенные CMS-фото в теле, чтобы дизайн не делал существующее поле незаметно неработающим.
13. Исправлена обнаруженная при интеграции Blade-компиляция ценовых блоков; реальные GET прайса и услуги проверены после исправления.
14. Исправлено наложение finder при увеличении текста до 200%: колонки переходят в стек по доступной ширине, названия меню не распадаются на отдельные слова.
15. По трассе найден поздний swap шрифтов; preload только Barlow 400/700 снизил измеренный локальный CLS с 0,109938 до 0,000140. Размеры изображений не маскировались под причину.
16. У строк прайса CTA больше не прыгает из-под названия на ту же строку в зависимости от длины заголовка.
17. Исправлен шаблон выбора E2E-файлов: admin-сценарий больше не запускается случайно в buyer-проекте; его отдельные desktop/390/320 admin-матрицы сохранены.
18. Акции на 320/390 px остаются доступны без JavaScript: все предложения идут естественным списком, полные условия раскрываются, неработающие стрелки скрыты. Устранена минимальная высота, растягивавшая квадратную карточку шире экрана.
19. Публичный formatter меняет только обозначение NOK → kr, не переписывая остальные обозначения валют; добавлены проверки нижнего регистра.
20. Отсутствие native-dialog API больше не прерывает остальные JS-компоненты; условия акций в таком браузере остаются обычным раскрываемым текстом.
21. На staging-снимках найдены разрывы длинных подписей обеих вкладок finder. Для узких экранов добавлены Reg.nr. / Dimensjon с сохранением полных accessible-name Registreringsnummer / Dekkdimensjon; при увеличении текста вкладки могут переходить в стек. Регрессия проверяет обе подписи, не только первую.
22. Усиленный узкий тест с текстом 200% выявил переполнение длинного CMS-заголовка, процесса/рейтингов/отзывов, контактного email/B2B и обрезание категорий finder/Dekkhotell. Исправлены переносы и адаптивные колонки, ограничен рост внутренних отступов. При ручном просмотре снимка дополнительно найден конфликт auto-placement иконки процесса с номером: явная первая колонка устраняет лишний третий track. Тест проверяет не только page overflow, но и обрезание категорий, положение иконки слева и полезную ширину текста ≥140 px. Контент не переписан.
23. В admin исправлены 44 px touch-target меню, понятная кнопка выхода на 320/390 px, авторская max-width форм, границы невалидных полей и связанные inline-ошибки. Список заявок остаётся карточным до достаточной ширины; на телефоне не дублируются select и resource-shortcuts.
24. Карточка заявки явно показывает `NEW`/`RENEW`/`LAST`, не дублирует legacy-поля при наличии структурированных автомобилей и предупреждает о недостающем номере комплекта. После его ввода предупреждение исчезает, а дата/resource/history сохраняются при возврате.
25. Найдена причина ложных admin Playwright-timeout: Vite встраивал в CSS локальный `ASSET_URL` другого порта. Сборка закреплена на same-origin `/build/`; собранная CSS содержит 26 корневых font-URL и 0 ссылок на localhost.
26. Нестабильный video-сценарий разделён по реальным browser-events: initial reduced-motion/manual opt-in и одно доставленное runtime-изменение. Удалён ненаблюдаемый быстрый round-trip; product JS и его семантика не менялись.

## Проверка и доказательства

- Интегрированный admin Playwright: **11/11 PASS** на desktop/390/320 без retries; клиентский flow, серверный поиск, рабочий день, ввод номера хранения, возврат фильтров и mobile shell. - Финальная сборка: CSS `app-DNYdr7i2.css`, JS `app-CKCevDiM.js`. CSS содержит 26 same-origin `/build/assets/` font-URL и 0 ссылок на `127.0.0.1`/`localhost`.
